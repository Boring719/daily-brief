# 每日国际简报

一个装在你电脑上的小软件：每天自动抓取十几家国际媒体的报道，让 AI 归并成"事件"、写成中文简报，并推到你的手机。

---

## 一、怎么用（三步）

1. **双击「创建桌面快捷方式.bat」**（只需一次）
2. 桌面上会出现「每日国际简报」图标，**双击它** → 浏览器自动打开今天的简报
3. 想要每天 8:00 自动生成并推到微信：双击「开机自启.bat」（只需一次，之后开机自动运行）

> 关闭那个黑窗口 = 停止网页服务。定时任务在后台单独跑，互不影响。
> 没配好定时任务时，随时双击「立即生成并推送.bat」手动来一份。

---

## 二、配置（只需要做一次）

### 1. 填入 DeepSeek 密钥（必做）

简报的翻译、归并、撰写、核查全部由 AI 完成，没有密钥只能看到英文标题。

1. 打开 <https://platform.deepseek.com/>，注册并登录
2. 左侧「API keys」→「创建 API key」→ 复制那串 `sk-` 开头的字符（只显示一次）
3. 左侧「充值」，充 10 元（按目前的用量，一天几分钱）
4. 把 `secrets.example.json` 复制一份，改名为 `secrets.json`
5. 用记事本打开 `secrets.json`，把密钥填进 `"deepseek_api_key"`

### 2. 配置手机推送（可选，但推荐）

**方式 A：邮件（最省事）**

以 QQ 邮箱为例：

1. 登录 QQ 邮箱 → 设置 → 账户 → 开启「POP3/SMTP 服务」
2. 按提示生成「授权码」（16 位字母），**这不是你的登录密码**
3. 在 `secrets.json` 里填：

```json
"email": {
  "enabled": true,
  "smtp_host": "smtp.qq.com",
  "smtp_port": 465,
  "sender": "你的QQ号@qq.com",
  "auth_code": "刚才生成的授权码",
  "recipients": ["你想接收的邮箱@qq.com"]
}
```

163 邮箱同理，把 `smtp_host` 改成 `smtp.163.com`。

**方式 B：微信推送（Server酱）**

1. 手机微信扫码登录 <https://sct.ftqq.com/>
2. 复制页面上的 **SendKey**（形如 `SCT123456T...`）
3. 在 `secrets.json` 里填：

```json
"webhook": { "enabled": true, "sendkey": "你的SendKey", "url": "" }
```

免费版每天 5 条额度，一天一份够用。

## 三、它是怎么保证"不是假新闻"的

| 环节 | 做法 |
| --- | --- |
| 来源 | 只用固定的 15 家正规媒体（美/英/法/以色列/土耳其/新加坡/台湾/中国大陆/巴西/阿根廷/非洲），不用自媒体、不用聚合号 |
| 归并 | 同一件事的多家报道合成一条，不重复刷屏 |
| 交叉确认 | 至少 2 家**不同机构**报道才标「多源确认」；只有 1 家标「单一来源」，读者自己判断 |
| 双道 AI | 第一道写稿，第二道逐条核对"这句话材料里有没有"，对不上就删掉或降级标注 |
| 溯源 | 每条都带原始报道链接，点开就能自己验证 |
| 冲突 | 不同媒体说法不一致时，如实写"有媒体称…另有媒体称…"，不替读者下结论 |

**它做不到的事**：AI 仍可能出错；标注为「单一来源」的条目要留个心眼；它不是通讯社，不能替代你自己核实重要信息。

## 四、目录说明

```
daily-brief/
├─ 启动简报.bat            双击打开网页
├─ 立即生成并推送.bat      不等定时，马上生成一份并推送
├─ 开启每日自动.bat        启动每天 08:00 的定时任务
├─ 创建桌面快捷方式.bat    在桌面放一个图标
├─ settings.json           新闻源、栏目、生成时间等（可改）
├─ secrets.json            你的密钥和邮箱（自己填，别外传）
├─ app/                    程序代码
├─ web/style.css           页面样式
├─ reports/                每天生成的 HTML 存档
├─ data/brief.db           历史记录数据库
└─ logs/                   运行日志
```

想改生成时间：编辑 `settings.json` 里的 `"schedule_time": "08:00"`，改完重启「开启每日自动.bat」。

页面顶部有实时进度条：抓取（显示已完成几家）→ 归并 → AI 筛选 → 撰写 → 核查 → 推送，完成会自动刷新。右上角「重新生成」可手动再来一份（会再花几分钱）。

想加/减新闻源：编辑 `settings.json` 的 `sources` 数组，把某家的 `"enabled"` 改成 `false` 即可停用。

## 五、常见问题

**Q：双击没反应 / 浏览器打不开？**
A：看那个黑色窗口里有没有报错。常见原因是端口被占用，程序会自动换端口，看窗口里打印的地址点进去。

**Q：显示"几乎没有抓到新闻"？**
A：网络问题。这些媒体里有一部分在国内访问不稳定，多试一次通常就好。

**Q：推送失败？**
A：多半是授权码填错（不是登录密码），或者邮箱没开 SMTP 服务。日志在 `logs/`。

**Q：电脑关机时会漏掉吗？**
A：会。定时任务只在电脑开机且登录时运行，关机错过的那天不会补发（可以双击「立即生成并推送.bat」手动补一份）。
